# NightCode

A terminal-based AI coding agent, powered by NVIDIA's free model catalog — plan, chat, and build inside your local project, with no paid API key required.

This repository root indexes two complete documentation sets:

The full engineering reference: architecture, database design, API contracts, authentication, AI model integration, the agent tool system, billing, deployment, security, testing, and more. Written for engineers building, operating, or extending NightCode.
