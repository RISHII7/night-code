# NightCode — Product Brochure

## Your AI Pair Programmer, Right in the Terminal — Free

NightCode brings a genuinely capable AI coding agent directly into your
terminal, working on your actual local project — reading files, searching your
codebase, writing and editing code, and running commands — without ever asking
for a credit card.

---

## Why Developers Choose NightCode

### 🖥️ Built for the terminal, not bolted onto it

NightCode isn't a chatbot in a sidebar or a browser tab you copy-paste between.
It's a full interactive terminal application — a command palette, live streaming
responses, session history, and theming — designed the way developers actually
want to work: without leaving the keyboard.

### 🆓 Frontier-class models, zero token billing

NightCode runs on NVIDIA's free hosted model catalog — including large-scale
Llama models, DeepSeek's advanced reasoning model, and a coding-specialized Qwen
model — so you get genuinely capable AI assistance without watching a per-token
meter run in the background.

### 🧭 Two clear modes: Plan, then Build

Start in **PLAN** mode for read-only research and proposals — the agent explores
and explains, but never touches a file. When you're ready, switch to **BUILD**
mode to let the agent write, edit, and run commands directly. You always know
exactly what capability the agent has at any moment.

### 💾 Sessions that follow you

Every conversation is saved automatically and tied to your account — pick up
exactly where you left off, on any machine, the moment you log back in.

### 🔒 Sandboxed by design

Every file operation is strictly contained to the project directory you opened
NightCode in. The agent can't wander outside your project, and every action it
takes is visible in your terminal as it happens — nothing runs silently.

---

## How It Works

1. **Install** the NightCode CLI with your package manager of choice.
2. **Log in** once — a quick browser-based sign-in, no password to manage.
3. **Open a session** inside any project directory.
4. **Chat, plan, and build** — switch modes as your task evolves from "help me
   understand this" to "make the change."
