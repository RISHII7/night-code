## Built On

NightCode stands on a great deal of open-source work. In particular:

| Project                                   | Role in NightCode                                       |
| ----------------------------------------- | ------------------------------------------------------- |
| [Bun](https://bun.sh)                     | Runtime, package manager, bundler, and test runner      |
| [OpenTUI](https://github.com/sst/opentui) | React reconciler targeting the terminal                 |
| [React](https://react.dev)                | Component model for the terminal UI                     |
| [Hono](https://hono.dev)                  | The API server framework                                |
| [Prisma](https://www.prisma.io)           | Database ORM and migrations                             |
| [Vercel AI SDK](https://sdk.vercel.ai)    | Model-agnostic streaming and tool-calling orchestration |
| [Zod](https://zod.dev)                    | Schema validation shared across client and server       |
| [PostgreSQL](https://www.postgresql.org)  | Durable storage                                         |

And on the open-weight model ecosystem — including the teams behind Llama,
DeepSeek, Qwen, Mixtral, and Nemotron — whose work makes a genuinely free AI
coding agent possible in the first place.
